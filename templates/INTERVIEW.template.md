# INTERVIEW.template.md — High-Leverage SOUL Discovery Interview

Use this interview to discover durable identity requirements without exhausting the user with a personality questionnaire.

Ask only questions whose answers materially change the design.

## 1. Role and Purpose

- What is this agent fundamentally responsible for?
- What durable outcome should it create across projects?
- What would “world-class” performance look like?

## 2. Relationship to the User

Choose the closest relationship archetype:

- co-founder;
- operator;
- specialist;
- advisor;
- critic;
- teacher;
- coach;
- sparring partner;
- hybrid.

Then ask:

- Should it challenge weak ideas proactively?
- Should it execute when enough context exists, or primarily advise?
- How much should it protect the user's attention by making decisions rather than presenting options?

## 3. Contrastive Behavior

Pick the most informative contrasts:

### Directness
- blunt and sharp;
- diplomatic but clear;
- highly tactful.

### Agency
- proactive on reversible work;
- balanced;
- cautious/approval-heavy.

### Output
- concise by default;
- moderate detail;
- teaching-heavy.

### Innovation
- experimental;
- pragmatic;
- conservative.

### Relationship
- supportive;
- challenging;
- balanced.

### Tone
- serious;
- warm;
- witty;
- eccentric;
- formal.

## 4. Truth and Uncertainty

Ask:

- When evidence is weak, should the agent research first, present uncertainty, or ask?
- Should it correct the user directly when the premise is wrong?
- What kinds of claims must always be verified?

## 5. Domain Judgment

Ask:

- What are the three to five principles that elite practitioners in this field understand that mediocre ones do not?
- What bad habits or fashionable mistakes should the agent aggressively resist?
- Which tradeoffs matter most in this domain?

## 6. Authority

Determine what it may do autonomously.

Classify:

### Usually autonomous
- reading;
- research;
- analysis;
- drafting;
- internal organization;
- reversible local work.

### Requires confirmation
- external messages;
- publication;
- spending;
- destructive changes;
- production actions;
- access changes;
- legal/financial commitments.

Customize to the domain.

## 7. Anti-Identity

Ask:

> What must this agent never become?

Prompt with examples only if needed:

- sycophantic;
- bureaucratic;
- corporate;
- arrogant;
- reckless;
- vague;
- overconfident;
- passive;
- verbose;
- manipulative.

## 8. Positive / Negative Examples

Ask for one or two examples of:

- an answer/style the user loves;
- an answer/style the user hates;
- a practitioner whose judgment is admired, without blindly copying identity.

Extract principles from examples rather than copying surface style mechanically.

## 9. Runtime

Ask where the SOUL will run:

- Hermes;
- OpenClaw;
- custom runtime;
- portable/multiple.

This changes deployment architecture, not necessarily core identity.

## 10. Existing Context

If an existing SOUL/IDENTITY/USER/AGENTS file exists, inspect it before drafting.

Do not create avoidable contradictions.

## Interview Compression Rule

Usually 3–5 high-leverage questions at a time is better than a giant questionnaire.

If the user's role description already answers a question, infer it and proceed.

## Final Discovery Summary

Before drafting, be able to state:

```text
Identity:
Purpose:
Relationship:
Top values:
Epistemic posture:
Domain first principles:
Autonomy:
Communication:
Must never become:
Runtime:
```

If these are clear, drafting can begin.
