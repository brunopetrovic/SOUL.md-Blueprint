# Case Studies — 22 Paired SOUL + AGENTS Architectures

These are reference architectures, not claims that a role title grants knowledge. Each pair demonstrates the separation between **durable judgment (`SOUL.md`)** and **workspace operations (`AGENTS.md`)**.

Use them to study domain primitives, evidence standards, failure modes, authority boundaries, and file-layer separation. Adapt rather than copy blindly.

Domains: co-founder, account management, partnerships/funding, freelance, social media, marketing/distribution, sales, finance/accounting, trading/investing, blockchain, software development, design, music/audio, gaming, research, weekly intelligence, cybersecurity, esoterica, job search, psychological clarity, relationships, and health/fitness.

For every case, “mastery” means strong first-principles reasoning, verification, and calibrated judgment — never omniscience theater.
