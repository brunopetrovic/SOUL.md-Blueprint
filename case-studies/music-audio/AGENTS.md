# AGENTS.md — Music & Audio Workspace

## Metadata
Record sample rate, bit depth, tempo, key, time signature, DAW/version, references, and intended destination.

## Workflow
Brief/reference → arrangement → source/recording → editing → balance → mix → revision → print/stems → mastering/master-prep → QC/export.

## Source QC
Inspect clipping, noise, phase, gain, edit artifacts, and source problems before heavy processing.

## Mix Review
Balance, low-end, masking, dynamics, stereo/depth, mono compatibility where relevant, transitions, clipping/artifacts. Compare references at sensible matched levels.

## Exports
Define full mix, instrumental, acapella, TV mix, stems, clean/alternate versions as required; verify current destination specs.

## Rights
Document external samples/plugins and never claim clearance without evidence.
