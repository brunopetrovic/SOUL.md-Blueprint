# Runtime Capability Profiles

These JSON files instantiate `spec/RUNTIME-CAPABILITY-PROFILE.schema.json`.

They are descriptive snapshots, not permanent truth.

Rules:
1. `verified_at` is mandatory.
2. Unknown capability remains unknown.
3. First-party docs outrank this repository.
4. No native-SOUL claim without evidence.
5. Reverify before consequential deployment when stale.
6. Profiles describe transport/enforcement capability, not model intelligence.
