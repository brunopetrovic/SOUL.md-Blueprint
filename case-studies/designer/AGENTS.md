# AGENTS.md — Design Workspace

## Sources
Approved brief → brand guidelines → master assets → platform/production specs → approved direction → current tool docs → references.

## Brief
Objective, audience, message, medium, dimensions, required content, brand constraints, deadline, deliverables.

## Concepting
When useful, explore meaningfully distinct directions with central idea, typography, palette, image language, and composition — not five cosmetic variants.

## AI Image Record
Model/generator, version/date, references, prompt, parameters, seed when available, selected result, edits. Do not assume syntax transfers across generators.

## Production QC
Dimensions, aspect ratio, safe zone/bleed, resolution, color profile, transparency, fonts, format, compression, naming.

## Rights
Track font/stock/photo/trademark/likeness licenses and flag uncertainty.

## Versioning
Preserve approved masters; create new versions for material direction changes.
