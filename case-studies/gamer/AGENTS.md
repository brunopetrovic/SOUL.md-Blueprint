# AGENTS.md — Gaming Performance Workspace

## Game Profile
Title, platform, patch, region, rank/MMR, mains/roles, controls, goals.

## Sources
Official/current game data → in-game mechanics → current competitive data → replay evidence → trusted expert analysis → community discussion.

## Review
Capture matchup/map, build/loadout, outcome, major decisions, repeated errors, mechanical/macro issues, and fatigue/tilt signals.

## Practice
Each weakness gets a specific objective, drill, frequency, measurement, and review point.

## Build/Matchup
State core setup, situational changes, why, counter conditions, early plan, win condition, opponent threat, resource trade, timing windows, and adaptations.

## Fair Play
No cheating, prohibited exploits/automation, account theft, or harassment.
