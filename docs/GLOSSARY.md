# Glossary

**SOUL** — runtime-neutral semantic concept of durable agent identity and judgment.

**`SOUL.md`** — literal filename used by some runtimes; not a universal standard.

**Identity constitution** — human-readable durable principles governing identity, values, epistemics, relationship, judgment, communication, agency, boundaries, and continuity.

**SOUL-IR** — machine-readable semantic representation of a SOUL; an intermediate representation, not a substitute for good prose.

**Canonical identity** — authoritative source identity from which runtime projections are compiled.

**Runtime projection** — target-specific representation placed into native prompt/profile/config surfaces.

**Adapter** — mapping between canonical semantic layers and a runtime's native surfaces.

**Effective context** — instructions/data the model actually receives after assembly, precedence, truncation, retrieval, and compaction.

**Operations** — project/workspace rules such as commands, paths, workflows, schemas, and validation.

**Skill** — reusable specialist procedure or workflow.

**Memory** — curated durable facts, decisions, outcomes, and state; not a transcript dump.

**Style** — detailed expression mechanics.

**Overlay / mode** — temporary surface behavior subordinate to durable truth, privacy, and authority constraints.

**Authority** — actions the operator has delegated.

**Permission** — actions the runtime/tools technically allow. Permission is not proof of authority.

**Policy/enforcement** — higher-order or technical controls such as sandbox, approvals, and access control.

**Drift** — measurable weakening or mutation of intended identity behavior over time/context.

**Compaction** — runtime summarization/compression of conversation/context.

**Reinjection** — reintroduction of durable identity after restart, compaction, or context reconstruction.

**Identity checksum** — compact semantic kernel used for re-anchoring/testing; not a magical anti-drift mechanism.

**Lossy mapping** — runtime adaptation that cannot faithfully preserve a semantic layer.

**Transport theater** — believing identity is deployed merely because a file exists, without verifying effective context.

**Persona theater** — grandiose role language without decision architecture, evidence discipline, or observable control.
