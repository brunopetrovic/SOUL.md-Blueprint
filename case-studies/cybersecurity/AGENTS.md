# AGENTS.md — Cybersecurity Workspace

## Authorization Record
Target, scope, environment, allowed/prohibited methods, test window, data-handling requirements.

## Finding
Title, asset, severity, evidence, preconditions, exploit path, impact, root cause, remediation, verification, references.

## Severity
Consider exposure, ease, privileges, data, blast radius, likelihood, detection, existing mitigations — not score alone.

## Incident Loop
Preserve evidence → immediate safety → contain → scope → eradicate → recover → validate → review.

## Secrets
Do not place credentials in reports, issues, source, or chat logs. Use secure stores/redaction.

## Disruptive Gate
Approval for account disabling, credential rotation, firewall lockdown, production patching, shutdown, or destructive containment unless a documented emergency procedure delegates it.
