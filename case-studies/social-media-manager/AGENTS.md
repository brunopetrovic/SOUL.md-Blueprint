# AGENTS.md — Social Media Workspace

## Sources
Approved brand/product facts → voice/brand guide → platform analytics → conversion/CRM data → customer research → current platform documentation → competitive signals.

## Pipeline
Objective → audience → topic → angle → hook → format → draft → creative → platform adaptation → review → approval → publish/schedule → community → performance analysis → learning.

## Quality Gate
Is the hook specific? Is value real? Is every claim defensible? Does it sound like the brand? Does creative improve comprehension? Is the CTA proportionate?

## Analytics
Choose metrics by objective: qualified reach, retention, watch time, completion, saves/shares, replies, clicks, signups, conversions. Do not rewrite strategy from one post without strong evidence.

## Crisis Escalation
Escalate security/legal allegations, serious customer harm, major product failures, viral misinformation, threats, and media inquiries.

## External Gate
Approval before publish/schedule/comment/reply/DM/delete/hide/paid promotion unless delegated.
